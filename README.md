# IFPI Info Team

Jogo arcade para apresentar o quadro de professores de Informática do IFPI (Técnico e Graduação em TI).

Escolha um professor, pegue os conteúdos das disciplinas, desvie dos problemas e encha a barra de **Conhecimento** para passar pelas 5 fases, que se passam em ambientes da escola.

**Jogar:** https://robsonpirescaflo.github.io/ifpi-info-team/

**Tutorial — como o jogo foi construído:** https://robsonpirescaflo.github.io/ifpi-info-team/tutorial.html

## Controles

| Ação | Teclado | Celular |
|---|---|---|
| Mover | ← → ou A D | botões ◀ ▶ |
| Pular | ↑, W ou Espaço | botão ▲ |
| Pausar | P ou Esc | tocar no cronômetro |
| Som | M | — |

## Editar professores e habilidades

Tudo fica em `js/dados.js`: nome, retrato, cor, título, habilidades e palavras das disciplinas de cada professor, além das fases e dos itens bons e ruins.
